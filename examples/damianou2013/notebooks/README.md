# Colab notebooks (Matlab-aligned)

Thin wrappers around the Python ports of [SheffieldML/deepGP](https://github.com/SheffieldML/deepGP) demos.
Each notebook installs deps on Colab, fetches scripts / reference `.mat` files, and calls the corresponding module.

See [../SOURCE.md](../SOURCE.md) and [../README.md](../README.md).
